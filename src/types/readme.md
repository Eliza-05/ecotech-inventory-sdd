# types

## Propósito
Interfaces, tipos y contratos TypeScript compartidos entre capas.

## Pertenece aquí
- Definiciones de datos y contratos usados por más de una capa.
- Solo declaraciones de tipos.

## No pertenece aquí
- Lógica, funciones con comportamiento o JSX.
- Dependencias hacia `components/`, `hooks/` o `services/`.

## Relación con otras capas
Lo importan todas las demás capas. No depende de ninguna.
